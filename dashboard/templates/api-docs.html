Signal API

Run self-custody betting from your own machine.

The recommended hands-off setup is still connecting Kalshi inside the app, because the server can run continuously. The Signal API is optional for users who prefer to keep Kalshi credentials only on their own computer or VPS.

Create API Token View Script

How it works

  1. Create an API token in Settings → API.
  2. Run the follower script on a machine you control.
  3. The script polls MLB Intelligence for model signals.
  4. The script places orders directly with Kalshi using your local key file.
  5. The script syncs order and balance updates back to the dashboard.

Your Kalshi private key stays on your machine. The tradeoff is uptime: if your machine is off, asleep, or disconnected, it cannot place bets.

Requirements

  • Python 3.10 or newer.
  • Project dependencies installed with uv sync.
  • Kalshi API key ID in KALSHI_KEY_ID.
  • Kalshi private key PEM path in KALSHI_KEY_PATH.
  • Signal API token from Settings → API.

Setup

1. Clone and install

git clone https://github.com/jeverett32/mlb-pipeline.git cd mlb-pipeline uv sync

2. Create environment file

MLBI_API_BASE_URL=https://your-mlb-intelligence-domain MLBI_API_TOKEN=your-token-from-settings KALSHI_KEY_ID=your-kalshi-key-id KALSHI_KEY_PATH=/absolute/path/to/kalshi-key.pem KALSHI_ENV=prod

3. Test with a dry run

uv run python scripts/run_signal_follower.py --once --dry-run

4. Run live once

uv run python scripts/run_signal_follower.py --once

5. Run continuously

uv run python scripts/run_signal_follower.py

API endpoints

Endpoint Purpose
GET /api/signals/upcoming Read current model signals for upcoming games.
POST /api/client/orders Sync local execution result back to the dashboard.
POST /api/client/balance Sync Kalshi balance snapshot from local machine.
POST /api/client/heartbeat Confirm follower script can authenticate and reach the server.
Authorization: Bearer your-token-from-settings

Running as a service

For reliable execution, run the script on a machine that stays online. A small VPS or always-on home server works better than a laptop.

[Unit] Description=MLB Intelligence signal follower After=network-online.target [Service] WorkingDirectory=/opt/mlb-pipeline EnvironmentFile=/opt/mlb-pipeline/.env ExecStart=/opt/mlb-pipeline/.venv/bin/python scripts/run_signal_follower.py Restart=always RestartSec=15 [Install] WantedBy=multi-user.target
Self-custody execution, optional.
