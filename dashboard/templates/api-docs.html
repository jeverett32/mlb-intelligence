Signal API

Run self-custody betting from your own machine.

The recommended hands-off setup is still connecting Kalshi inside the app, because the server can run continuously. The Signal API is optional for users who prefer to keep Kalshi credentials only on their own computer or VPS.

Create API Token Download Script Open Script

Overview

  1. Create an API token in Settings > API.
  2. Turn on Use API Endpoint in Settings > Betting before live local execution.
  3. Download the standalone follower script and edit the config variables at the top.
  4. The script polls MLB Intelligence for model signals.
  5. The script places orders directly with Kalshi using your local key file.
  6. The script syncs order and balance updates back to the dashboard.
  7. The dashboard tracks the script heartbeat, so stale runner status means the local machine is off, asleep, or disconnected.

Your Kalshi private key stays on your machine. The tradeoff is uptime: if your machine is off, asleep, or disconnected, it cannot place bets.

Requirements

  • Python 3.10 or newer.
  • Python packages: requests and cryptography.
  • Kalshi API key ID.
  • Kalshi private key PEM file saved locally.
  • Signal API token from Settings > API.
  • Use API Endpoint turned on in Settings > Betting if DRY_RUN = False.

Setup

1. Download the script

curl -O https://mlb.johnreverett.com/static/self_custody_follower.py

2. Install dependencies

python -m pip install requests cryptography

3. Edit the config block

MLBI_API_BASE_URL = "https://mlb.johnreverett.com" MLBI_API_TOKEN = "paste-your-api-token" KALSHI_KEY_ID = "paste-your-kalshi-key-id" KALSHI_KEY_PATH = "kalshi-key.pem" KALSHI_ENV = "prod" DRY_RUN = True

4. Test with dry run enabled

python self_custody_follower.py

5. Turn on live execution

After the dry run behaves as expected, change DRY_RUN = False and run the script on a machine that stays online.

Endpoints

Endpoint Purpose
GET /api/signals/upcoming Read current model signals for upcoming games.
POST /api/client/orders Sync local execution result back to the dashboard.
POST /api/client/balance Sync Kalshi balance snapshot from local machine.
POST /api/client/heartbeat Confirm follower script can authenticate and update runner last-seen status.
Authorization: Bearer your-token-from-settings

Run as a service

For reliable execution, run the script on a machine that stays online. A small VPS or always-on home server works better than a laptop.

[Unit] Description=MLB Intelligence signal follower After=network-online.target [Service] WorkingDirectory=/opt/mlb-pipeline ExecStart=/usr/bin/python /opt/mlb-pipeline/self_custody_follower.py Restart=always RestartSec=15 [Install] WantedBy=multi-user.target
