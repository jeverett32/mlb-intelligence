Setup Guide

Connect your Kalshi account.

MLB Intelligence places bets on Kalshi using your API key. Kalshi does not offer OAuth, so you need to generate an API key on Kalshi and paste it here. Takes about 2 minutes.

Open Settings Open Kalshi profile

What you'll need

  • An active Kalshi account.
  • Your Kalshi Key ID (a UUID-style string).
  • Your Kalshi private key PEM file (downloaded once when you generate the key).

Heads up: Kalshi only shows the private key file at creation time. Save the .pem file somewhere safe — you cannot download it again.

Step-by-step

1Generate the API key on Kalshi

  1. Open kalshi.com/account/profile and log in.
  2. Navigate to the API Keys section.
  3. Click Create API Key.
  4. Download the private key file (it will be named like kalshi-key.pem).
  5. Copy the Key ID shown next to the new key.

2Paste the Key ID into Settings

  1. Open Settings > Kalshi.
  2. Enter a Label (any name to remember the account).
  3. Paste the Key ID.
  4. Pick the Environment — prod for real money, demo for test.

3Add the private key PEM

  1. Drag the downloaded .pem file onto the drop zone, or click to browse.
  2. Or open the file in a text editor and paste its contents into the textarea.
  3. Click Connect & Test.

The app will sign a request to Kalshi to verify the key works and pull your current balance. If it works, you'll see your balance show up in the status card.

4Done

Your private key is stored encrypted on the server and only used to sign Kalshi API calls for your account. You can disconnect at any time.

Disconnecting

Open Settings > Kalshi and click Disconnect. The stored key file is deleted from the server and the app will stop placing bets. Revoke the key on Kalshi too if you no longer want it active anywhere.

Troubleshooting

"Connection test failed"

  • Confirm the Key ID matches what Kalshi shows on the API keys page exactly.
  • Confirm you pasted the entire PEM including -----BEGIN PRIVATE KEY----- and -----END PRIVATE KEY-----.
  • Confirm the environment matches where the key was generated (prod vs demo are separate).
  • If Kalshi shows the key as revoked or expired, generate a new one and reconnect.

"Balance shows $0.00"

The connection works — Kalshi is reporting a zero balance. Deposit funds on Kalshi and refresh.

Security

  • The PEM is stored on the server with restricted permissions and used only to sign Kalshi requests for your account.
  • Only your authenticated session can read or update it; other users cannot see or use it.
  • Disconnect deletes the key file from the server.
  • If you prefer to keep the PEM only on your own machine, use the self-custody Signal API instead.
