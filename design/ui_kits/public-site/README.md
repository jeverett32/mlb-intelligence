# Public site UI kit

Hi-fi recreation of the public-facing surface (`/`, `/public`, `/login`, `/register`, `/contact`, `/privacy`).
Source: `dashboard/templates/landing.html`, `dashboard/templates/public.html`, `dashboard/static/css/public-site.css`.

## Components
- `Topbar.jsx` — brand + nav links, scrolls with page (not sticky)
- `Hero.jsx` — headline + lead + CTA + glass demo panels + orbits
- `MetricsGrid.jsx` — trust-metrics strip with 4 KPIs
- `ProcessSteps.jsx` — numbered methodology steps
- `AnalyticsKPIs.jsx` — three glass overview cards (Model / Market / ROI)
- `ReceiptsTable.jsx` — settled bets with W/L pill, edge, return
- `Footer.jsx`
